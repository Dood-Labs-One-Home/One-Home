# Rollies 🎳

Rollies is a retro arcade bowling alley game built for the browser. Start with a full 10-frame bowling game, unlock the Rollies Pool Room, clear the pool table, and discover the hidden Speak Easy Rollie Casino.

## Features

- 🎳 Arcade-style bowling
- 🎱 Unlockable Rollies Pool Room
- ✨ Hidden Speak Easy unlock after clearing pool
- 🎰 Basic slot machine mini-game
- 🃏 Basic card room mini-game
- 🔊 Bowling alley music and sound effects
- 📱 Mobile, tablet, and desktop friendly
- 🌐 Built as a single-file browser game for GitHub Pages

## How to Play

Pull back, aim, and release to bowl. Finish a full game to unlock the Pool Room. Sink every pool ball to unlock the hidden Speak Easy Rollie Casino.

Casino games use arcade tokens only. No real money or gambling.
