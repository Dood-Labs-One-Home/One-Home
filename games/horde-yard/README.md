# HORDE Yard

HORDE Yard is a browser-based XRPL zombie collector prototype for the HORDEonXRPL community.

The game turns wallet activity into an evolving zombie yard. Players earn Horde Points through holding, collecting, adding liquidity, trading, and participating in community events. As points grow, the yard unlocks zombies, props, rare visitors, boss zombies, and future rewards.

This first version is a simple shareable MVP built in one `index.html` file so it can be deployed quickly through GitHub Pages.

## Current MVP Features

- Mock Xaman wallet connection
- Mock Horde Points system
- Unlockable zombie yard scene
- Leaderboard preview
- Event preview cards
- Mobile-friendly layout
- Share text button
